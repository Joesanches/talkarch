# «Консилиум» — корпоративный медицинский мессенджер

«Консилиум» — рабочее название. Это мессенджер для врачей, лаборантов и инженеров:

- **с эргономикой Telegram;**
- **встраивается в РИС, ЛИС (патоморфология) и телемедицинские системы;**
- **работает отдельными приложениями** на ПК (Windows, Astra Linux, РЕД ОС, macOS) и смартфонах (iOS, Android).

Главная идея — **чат случая**. Переписка привязана к конкретному исследованию: участники подбираются по ролям, в чате есть карточка случая, ключевые снимки и ROI препаратов со ссылкой во вьюер, заявки со статусами из ЛИС и критические находки с подтверждением получения.

## Рекомендация в двух словах

- **Основа:** Matrix (протокол и сервер — Synapse или Tuwunel), собственные клиенты на SDK под Apache-2.0 и собственный сервис клинического контекста — он связывает чаты с РИС/ЛИС.
- **План Б — Zulip,** если пилот покажет, что не нужны федерация между организациями, свои типы сообщений и встроенные звонки.

## Макеты

Интерактивный холст: <https://claude.ai/artifact/HYEy2arBVNpiLeCrpGLvDU>. Он приватный — откройте доступ через «Поделиться».

На холсте:

- десктоп;
- встраивание в РИС и ЛИС;
- шесть мобильных экранов (список, чат случая, критическая находка, врач — инженер, врачебный канал, видеоконсилиум);
- дизайн-система.
