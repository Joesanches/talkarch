# «Консилиум» — корпоративный медицинский мессенджер

«Консилиум» — рабочее название. Это мессенджер для врачей, лаборантов и инженеров:

- **с эргономикой Telegram;**
- **встраивается в РИС, ЛИС (патоморфология) и телемедицинские системы;**
- **работает отдельными приложениями** на ПК (Windows, Astra Linux, РЕД ОС, macOS) и смартфонах (iOS, Android).

Главная идея — **чат случая**. Переписка привязана к конкретному исследованию: участники подбираются по ролям, в чате есть карточка случая, ключевые снимки и ROI препаратов со ссылкой во вьюер, заявки со статусами из ЛИС и критические находки с подтверждением получения.

## Рекомендация в двух словах

- **Основа (согласовано):** Matrix (протокол и сервер — Synapse или Tuwunel), собственные клиенты на SDK под Apache-2.0 и собственный сервис клинического контекста — он связывает чаты с РИС/ЛИС.
- **Видеосвязь, вебинары, запись (согласовано):** LiveKit в контуре организации, вход только для участников комнаты. Вебинары на сотни и тысячи зрителей, включая внешних врачей, — в отдельной зоне DMZ через HLS.
- **ИИ (первая очередь согласована):** стенограмма и черновик протокола консилиума на локальных моделях (LiveKit Agents, GigaAM / Whisper, LLM с открытыми весами). Работает и без GPU — в режиме «только CPU», итоги позже.
- **Чаты случаев:** комната на случай, ленивое создание, архив с выводом участников — подход выдерживает рост на годы вперёд.
- **План Б — Zulip,** если пилот покажет, что не нужны федерация между организациями, свои типы сообщений и встроенные звонки.

## Разработка

Идёт этап 0 (PoC). План и статус — в [docs/09-dev-plan.md](docs/09-dev-plan.md), запуск окружения — в [infra/README.md](infra/README.md).

```bash
pnpm install
pnpm test                               # модульные тесты
cd infra && docker compose up -d && cd ..
pnpm test:it                            # интеграционные тесты на Synapse
```

| Каталог | Что внутри |
|---|---|
| `apps/ccs` | Сервис клинического контекста (Matrix Application Service) |
| `packages/protocol` | Типы и схемы событий «чата случая» |
| `packages/tokens` | Дизайн-токены и проверка контраста |
| `infra` | Окружение разработчика: PostgreSQL, Synapse, LiveKit |
