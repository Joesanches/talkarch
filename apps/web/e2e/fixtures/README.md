# Тестовая речь

Вместо микрофона в сквозном тесте ИИ-«Секретаря» (`secretary.spec.ts`) — синтезированные фразы, вымышленные данные. Chromium читает файл по кругу (`--use-file-for-fake-audio-capture`).

| Файл | Кто «говорит» | Текст |
|---|---|---|
| `speech-pathologist.wav` | Смирнова А. В., патоморфолог | «По результатам иммуногистохимии рецепторы эстрогена положительные. Опухоль низкой степени злокачественности.» |
| `speech-attending.wav` | Колесников Д. А., лечащий врач | «Предлагаю гормональную терапию и контрольное исследование через три месяца.» (после 3 с тишины) |

Синтез — RHVoice (голоса `anna` и `aleksandr`, данные голосов под LGPL-2.1+), затем 16 кГц моно PCM:

```bash
echo "…" | RHVoice-test -p anna -o raw.wav
ffmpeg -i raw.wav -af "apad=pad_dur=2" -ar 16000 -ac 1 -c:a pcm_s16le speech-pathologist.wav
```

RHVoice — только инструмент для подготовки файлов, в продукт и зависимости не входит.
