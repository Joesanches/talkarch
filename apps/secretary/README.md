# ИИ-«Секретарь»: агент стенограммы

Агент входит в звонок LiveKit как участник «Секретарь (запись речи)» **только на приём** (токен без права публикации выдаёт сервис контекста), подписывается на аудиодорожку каждого участника и распознаёт её отдельным потоком. Поэтому реплики подписаны точно, диаризация не нужна. Подробно — [docs/08-video-ai.md](../../docs/08-video-ai.md), раздел 5.

```
кнопка «Стенограмма» → сервис контекста POST /sessions → агент в звонке
  дорожка участника (WebRTC, 16 кГц моно) → Vosk (WebSocket) → фразы с метками времени
«Остановить» / конец звонка (15 с без людей) / 4 часа → стенограмма → POST {callback_url}
  сервис контекста: стенограмма в чат → черновик протокола (LLM) → чат случая
```

## API

Авторизация — `Authorization: Bearer $SECRETARY_TOKEN` (общий секрет с сервисом контекста).

| Метод | Назначение |
|---|---|
| `POST /sessions` | `{session_id, livekit_url, token, asr_url?, callback_url, callback_token}` → 201. Без `asr_url` — `ASR_URL` агента |
| `DELETE /sessions/{id}` | Остановить: агент дочитывает звук и отдаёт результат → 202; неизвестная сессия — 404 |
| `GET /healthz` | Живость и число сессий |

Результат — `POST {callback_url}` с `{session_id, started_at, ended_at, participants, segments: [{i, speaker, name, start_ms, end_ms, text}], asr}`. Время — целые миллисекунды: в событиях Matrix дробные числа запрещены. При недоступности сервиса — 5 повторов с паузой.

## Запуск

В окружении разработчика — профиль `ai` в [infra/docker-compose.yml](../../infra/README.md). Локально:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt pytest==9.1.1
SECRETARY_TOKEN=dev-only-secretary-token-0123456789 ASR_URL=ws://localhost:2700 .venv/bin/python -m secretary.app
.venv/bin/python -m pytest      # модульные тесты сборки стенограммы
```

Зависимости: `livekit` (Apache-2.0), `aiohttp` (Apache-2.0), `websockets` (BSD-3-Clause). Распознавание — vosk-server с моделью kaldi-ru (Apache-2.0); движок заменяемый — следующий кандидат GigaAM / Whisper (сравнение по WER на медицинской речи).

## Ограничения PoC

- Нет живых субтитров и деления стенограммы по случаям повестки.
- Сессии — в памяти агента и сервиса контекста: перезапуск во время звонка теряет итоги этого звонка (сервис честно сообщает об этом в чате при «Остановить»).
- Пока микрофон участника выключен, кадры не приходят; агент дописывает тишину, чтобы метки времени не сдвигались.
