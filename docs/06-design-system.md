# Дизайн-система и корпоративный стиль

> Брендбук пока не получен, поэтому все значения — заглушки на нейтральной «клинической» палитре. Схема устроена так, что переход на корпоративный стиль меняет только токены, а не экраны.
>
> Токены: [../design/tokens.json](../design/tokens.json). Наглядно — артборд «Дизайн-система» на холсте макетов.

## 1. Как устроено

Три уровня токенов:

1. **Бренд:** один цвет `brand.accent` и шрифты. Это всё, что нужно взять из брендбука.
2. **Семантика:** `accent.text`, `accent.soft`, `bubble.out`, `bubble.out-meta`, тёмная тема, нейтральные цвета, статусы (`critical`, `warning`, `success`), типы чатов.
3. **Компоненты:** пузыри, бейджи, карточки, кнопки ссылаются только на семантику.

Производные цвета вычисляются из бренда смешением каналов sRGB, `mix(a, b, k)`:

| Токен | Формула | Значение для `#1F6FB2` |
|---|---|---|
| `accent.text` | `mix(accent, #000, 0.15)` | `#1A5E97` |
| `accent.soft` | `mix(accent, #FFF, 0.88)` | `#E4EEF6` |
| `bubble.out` | `mix(accent, #FFF, 0.85)` | `#DDE9F3` |
| `bubble.out-meta` | `mix(accent, #000, 0.30)` | `#164E7D` |
| `dark.bubble-out` | `mix(accent, #0E141B, 0.50)` | `#174267` |

Контраст (WCAG 2.1) проверен для четырёх пресетов. Минимальные значения:

- белый на акценте — 4,99 (терракота);
- ссылка на белом — 6,40;
- метаданные в исходящем пузыре — 6,82;
- служебный текст на приглушённом фоне — 4,91.

Если корпоративный цвет даёт белому тексту контраст ниже 4,5:1 (например, светло-голубой или жёлтый), то для заливок берём затемнённый вариант, а исходный цвет оставляем для иллюстраций и логотипа.

## 2. Как перейти на корпоративный стиль

1. Получить брендбук: основной цвет, шрифты (и лицензию на встраивание в приложения), логотип, правила иконок, примеры интерфейсов существующих продуктов.
2. Заполнить `brand.accent` и `brand.font.*` в `tokens.json`.
3. Сгенерировать платформенные темы (Style Dictionary или аналог): CSS-переменные для веба и десктопа, Kotlin (Compose) для Android, Swift для iOS.
4. Автоматически проверить контраст: генератор падает, если пара токенов ниже 4,5:1.
5. Подготовить white-label пакет: название приложения, иконка, заставка, заголовки push-уведомлений, тексты «О программе», домены.
6. Проверить на трёх эталонных экранах: десктоп, встраивание в РИС, мобильный чат случая.

Пресеты на холсте («Клинический синий», «Бирюзовый», «Фиолетовый», «Терракота») показывают, что меняется при смене бренда. В настройках холста можно задать любой свой цвет акцента.

## 3. Цвета

- **Нейтральные:**
  - поверхность `#FFFFFF`;
  - приглушённая `#F1F4F7`;
  - фон ленты `#E7ECF1` с точечной сеткой (собственный узор вместо «обоев» Telegram);
  - границы `#E1E7ED` / `#D5DDE5`;
  - текст `#16202B`, вторичный `#4E5A68`, метаданные `#5F6B7A`.
- **Статусы:**
  - критично: `#C62828`, текст `#A3191B`, фон `#FDE8E8`;
  - внимание: текст `#864700`, фон `#FFF1DD`;
  - готово: текст `#17663A`, фон `#E6F4EA`.
- **Типы чатов** (цвет аватара):
  - патоморфология `#9D2A5E`;
  - лучевая диагностика `#334155`;
  - сервис `#B45309`;
  - консилиум `#4338CA`;
  - ТМК и внешние `#0F766E`;
  - канал `#1F5F8B`.
- **Аватары людей:** восемь цветов, белые инициалы с контрастом ≥ 4,9:1.

## 4. Типографика

| Стиль | Шрифт | Размер / интерлиньяж |
|---|---|---|
| Заголовок экрана | Golos Text 600 | 22/28 |
| Название чата | Golos Text 600 | 15/20 |
| Текст сообщения | Golos Text 400 | 14,5/21 (мобильные 15/21) |
| Подпись, роль | Golos Text 500 | 12,5/17 |
| Метаданные | Golos Text 400 | 12/16 |
| Идентификаторы | JetBrains Mono 500 | 14/20 |

Оба шрифта — под OFL, с кириллицей; их можно встраивать в приложения. При наличии корпоративного шрифта заменяется только `brand.font.ui`. Моноширинный шрифт для номеров исследований стоит оставить: он помогает сверять номера.

## 5. Иконки

- Собственный контурный набор: сетка 24 px, толщина линии 1,8, скругления.
- Фирменные знаки сторонних мессенджеров (самолётик Telegram и т. п.) не используем.
- Эмодзи не используем как элементы интерфейса. Реакции — это статусы с иконками.

## 6. Компоненты

- **Аватары.** Человек — круг; случай — скруглённый квадрат с кодом (КТ, МРТ, ГИСТ, ИГХ, ТМК). Значки поверх: «в сети», «внешняя организация».
- **Бейджи:**
  - непрочитанное — акцент;
  - без звука — серый `#6B7785`;
  - критическое — красный с иконкой.
- **Чипы статусов:** этап, срок, CITO, «Решено», «В работе».
- **Пузыри.** Радиус 16 и 5 px со стороны отправителя. Время и галочки — внутри, внизу справа. Цитата ответа — тонированный блок без цветной полосы слева.
- **Реакции-статусы:** Принято, Согласен, Видел, Вопрос, Срочно.
- **Карточки внутри пузыря:**
  - заявка: заголовок, поля, ход выполнения, источник статуса;
  - критическая находка: красная обводка, обязательное действие;
  - неисправность: аппарат, влияние, вложения;
  - заключение: статус подписи.
- **Кнопки:**
  - основная — акцент;
  - вторичная — обводка;
  - тональная — `accent.soft`;
  - опасная — «Подтвердить получение»;
  - inline-кнопки под сообщением.
- **Карточка случая** над лентой: маскированное ФИО, «Показать», этап, срок, ссылки в РИС/ЛИС и вьюер.

## 7. Темы и плотность

- **Тёмная тема:**
  - фон `#0E141B`, поверхность `#18212B`, входящий пузырь `#1E2833`;
  - исходящий выводится из бренда;
  - текст `#E8EEF4`, вторичный `#9AA7B4` (7,55:1).
- **Плотность:**
  - `regular` для мобильных;
  - `compact` для рабочих станций РИС/ЛИС: строка списка 56 px вместо 68, меньше отступы.
- **Встраивание.** Хост передаёт `accent`, схему и плотность; остальное вычисляется теми же формулами.

## 8. Что намеренно не так, как в Telegram

- Свои иконки, узор фона, цвета и логотип: эргономика берётся, фирменный стиль — нет.
- Выделенная строка списка — мягкий фон, а не сплошная заливка акцентом. Спокойнее при долгой работе.
- Реакции-статусы вместо эмодзи.
- Аватар случая — квадрат, а не круг. Сразу видно, где человек, а где исследование.
