# UX: эргономика Telegram с медицинскими адаптациями

## 1. Принципы

1. **Привычное.** Раскладка, жесты и сочетания клавиш — как в Telegram. Обучение не должно требоваться.
2. **Контекст важнее канала.** Пользователь общается про исследование, а не «в канале». Карточка случая и ссылки во вьюер видны всегда.
3. **Однозначность.** Реакции и кнопки несут смысл («Принято», «Подтвердить получение»), а не эмоцию; их значение фиксируется в журнале.
4. **Тихо, пока не важно.** Обычные сообщения не отвлекают. Критическое — громко и с подтверждением.
5. **Приватность по умолчанию.** ФИО скрыто; на экране блокировки и в push нет ПДн.

## 2. Соответствие функциям Telegram

| Telegram | В «Консилиуме» | Медицинская адаптация |
|---|---|---|
| Три колонки на десктопе, папки слева | Так же: рейка папок, список, лента, панель информации | Папки по умолчанию: Все, Случаи, Личные, Каналы, Лаборатория, Сервис, Архив + пользовательские |
| Закреплённые чаты, архив | Так же | Закрытые случаи уходят в архив автоматически |
| Закреплённое сообщение | **Карточка случая** над лентой | Данные из РИС/ЛИС: этап, срок, приоритет; ФИО скрыто, раскрытие журналируется |
| Ответ, пересылка, правка, удаление | Так же | Пересылка из чатов случаев только внутри контура. Удаление оставляет «Сообщение удалено автором» и запись в аудите |
| Реакции-эмодзи | **Реакции-статусы:** Принято, Согласен, Видел, Вопрос, Срочно | Однозначный смысл, контурные иконки; набор настраивается |
| Голосовые и видеосообщения | Голосовые с **расшифровкой** | Расшифровка на сервере организации; «кружков» нет |
| Боты и inline-кнопки | **Карточки действий:** заявки, подтверждения, «Решено / Повторяется» | Двусторонняя синхронизация с РИС, ЛИС и сервис-деском |
| Mini Apps | **Виджеты:** вьюер, форма направления, протокол | Открываются в контексте случая, с правами пользователя |
| Каналы с комментариями | Врачебные каналы отделений | Отметка «Ознакомлен» для обязательных публикаций |
| Группы с темами (форумы) | Пространства: отделение, консилиум; темы — комнаты | Тема консилиума = чат случая, без дублирования |
| Звонки и видеочаты | 1:1, групповые, демонстрация экрана | Видеоконсилиум; запись — только по политике и с уведомлением |
| Секретные чаты | Сквозное шифрование в личных чатах (по политике) | Не для чатов случаев: им нужны аудит, архив и поиск |
| Код-пароль | PIN или биометрия, автоблокировка | Обязательны на мобильных; запрет скриншотов в чатах случаев (Android) |
| «Был в сети» | **Статус смены:** на смене, дежурство, не на смене | Ролевая адресация: `@дежурный_рентгенолог` → тот, кто сейчас дежурит |
| Поиск с фильтрами | По тексту, № случая, модальности, дате, типу вложения | Поиск по ФИО — через РИС/ЛИС с проверкой прав |
| Избранное | Избранное и «Учебные случаи» | При сохранении в учебные материал обезличивается |
| Несколько аккаунтов | Несколько организаций (федерация) | Значок внешней организации у пользователей и чатов |

| Экран | Что показано | Интерактив в макете |

| Мобильный · критическая находка | Ключевой снимок, карточка критической находки, быстрые ответы | «Подтвердить получение» |

## 4. Поведение и детали

**Список чатов**

- Порядок: закреплённые, затем по последней активности. Критическая находка, ожидающая подтверждения, поднимается наверх и получает красный бейдж.
- Аватар человека — круг, аватар случая — скруглённый квадрат с кодом модальности (КТ, МРТ, ГИСТ, ИГХ). Цвет подсказывает источник: РИС, ЛИС, сервис, консилиум, внешняя МО.
- В превью — имя отправителя в группах; статус заявки (например, «Решено») — чипом справа.

**Лента**

- Разделители дат и «Непрочитанные сообщения». Кнопка «вниз» со счётчиком.
- Своё сообщение — справа, на фоне `bubble.out` (выводится из цвета бренда). Чужое — слева, белое; у имени — роль («лаборант ИГХ»).
- Цитата ответа — тонированный блок со значком «ответ», без цветной левой полосы.
- Время и галочки (отправлено / прочитано) — в правом нижнем углу пузыря.
- Карточки (заявка, критическая находка, неисправность) — внутри пузыря: заголовок, поля, ход выполнения, действия.

**Поле ввода**

- Вложения, «Снимок из вьюера» (во встроенном режиме), шаблоны ответов, голосовое или «Отправить».
- Над полем — быстрые действия случая: Запрос ИГХ, Дорезка / пересмотр, Второе мнение, Сообщить инженеру. Набор зависит от роли и системы.

**Критическая находка**

- Получатель: push с высоким приоритетом, карточка закреплена вверху списка, большая кнопка «Подтвердить получение».
- Отправитель видит «прочитано», «подтверждено» и обратный отсчёт до эскалации.

**Уведомления**

- Режим «не беспокоить» привязан к графику смен; критические находки его обходят по правилам организации.
- Каналы по умолчанию — без звука.

**Горячие клавиши (десктоп)**

| Клавиши | Действие |
|---|---|
| Ctrl+K | Быстрый переход |
| Ctrl+F | Поиск в чате |
| Alt+↑ / Alt+↓ | Предыдущий / следующий чат |
| Ctrl+1…9 | Папки |
| ↑ | Редактировать последнее сообщение |
| Ctrl+Shift+M | Выключить или включить звук |
| Esc | Закрыть панель или выйти из ответа |

**Мобильные жесты**

| Жест | Действие |
|---|---|
| Свайп сообщения влево | Ответить |
| Долгое нажатие | Меню: ответить, переслать, реакция, копировать, в избранное |
| Свайп чата | Закрепить, без звука, в архив |

**Пустые состояния** объясняют, что будет: «Случаи переносятся сюда автоматически после подписания заключения».

## 5. Доступность и эргономика

- Контраст текста — не ниже 4,5:1 (проверено для всех пресетов, см. [06-design-system.md](06-design-system.md)).
- Зоны касания на мобильных — не меньше 44×44 px.
- Масштабирование шрифта до 200 % без потери функций; режим плотности `compact` для рабочих станций с мелкой графикой.
- Цвет не единственный носитель смысла: критичность дублируется иконкой и текстом.
- Полная навигация с клавиатуры; у кнопок-иконок есть подписи для экранного диктора.
- Тёмная тема — по системе или вручную. Рекомендуется для работы рядом с диагностическим монитором.
